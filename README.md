# FPS Arena Expanded
Open `index.html` in a browser, or deploy the folder with GitHub Pages.

Controls:
- WASD: move
- Space: jump
- Mouse: shoot
- 1-4: switch the four inventory slots
- R: reload

Included systems: jumping, boost pistol, tier progression, knife speed, bomb slot, enemy weapons, enemy-vs-enemy behavior when they cannot see the player, large procedural arena, round timer/rewards, directional enemy cue, drops, headshot multiplier, lobby, daily reward, shop placeholder, player loadout, ranked toggle, auto reload logic, bot cap/respawn, boost pads, multiple guns, sniper one-shot, RPG tier behavior.
